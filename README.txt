VISHAL BOSS WEBSITE — READY FOR GITHUB PAGES

1. Upload every file and the assets folder to your GitHub repository.
2. Keep all filenames and folder names unchanged.
3. Open index.html first. It shows the first photo and NEXT button.
4. Every main option has its own HTML page and a BACK button.
5. Telegram: Owner, stylish VishalxDevil, Support, Contact and My Bots.
6. My Bots expands: Niki, Niki Music and Nexus.
7. Social page contains WhatsApp, 2 YouTube links, 2 Instagram links and Cryptogram.
8. Projects contains NikiXMusic and Cryptogram.
9. Gallery contains 5 supplied images with Previous/Next controls.
10. To replace photos later, replace files inside assets using the same filenames.

IMPORTANT:
- The website uses Google Fonts through CSS @import. If you want fully offline fonts, replace the font import with local fonts.
- GitHub Pages will automatically serve the HTML files after Pages is enabled.
